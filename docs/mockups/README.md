# Mockups

Three takes on the dashboard and pipeline from `docs/spec.md`. They use the same figures, brand tokens and chart code (`shared/`), and differ in layout. Open each file in Chrome. Hovering over a chart shows its tooltip, and ticking a follow-up marks it done.

- **A: Classic** (`a-classic.html`): a white sidebar, four figure tiles, then charts and lists in pairs. Familiar and even.
- **B: Spotlight** (`b-spotlight.html`): navigation across the top, a large serif greeting, and a hero panel that puts revenue won front and centre with a wide line chart. More spacious.
- **C: Command** (`c-command.html`): a narrow Midnight icon rail, the figures and charts in the middle, and a "Your day" column on the right that keeps follow-ups and recent activity in view. Densest.

**Chosen: C, Command.** It is the reference for Build. Each mockup also has a working Pipeline view (click Pipeline in its navigation): drag cards between and within columns, and use + on a column to add a deal at that stage. The totals update as cards move. The mockups load fonts from Google Fonts. The app itself bundles them so it works offline.
